 Project Overview
This project analyzes coffee shop transaction data using Microsoft Power BI to understand overall sales performance, customer purchasing patterns, product performance, and sales trends over time. The dashboard transforms transaction-level data into an interactive and easy-to-understand report that helps identify important patterns in coffee sales.

The dashboard includes key performance indicators such as Total Sales, Total Transactions, and Average Transaction Value, along with visual analysis of monthly sales trends, revenue by coffee type, revenue by time of day, and product performance. These analyses provide a clear view of business performance and help identify areas of strong demand and changing sales patterns.

 Key Insights

1 Latte was the highest revenue-generating coffee, contributing approximately $26.9K in revenue.
2 Americano with Milk recorded the highest transaction volume, with approximately 809 transactions.
3 Espresso was the lowest-performing product by revenue.
